#  Clone X

Clone X est une application web inspirée de **Twitter (X)**, développée avec **AdonisJS 6**, **TailwindCSS** et **PostgreSQL**.  
Elle permet aux utilisateurs de s’inscrire, de se connecter, de publier des tweets, d’aimer, de commenter et de suivre d’autres utilisateurs — tout en conservant une interface moderne et fluide.

---

##  Fonctionnalités principales

###  Authentification
- Inscription avec validation des données (nom, email, mot de passe).
- Connexion en deux étapes (email puis mot de passe).
- Gestion sécurisée des sessions et erreurs.

###  Tweets
- Création, affichage et suppression de tweets.
- Possibilité de retweeter et de commenter un post.
- Affichage chronologique des publications (timeline).

###  Interactions
- Système de **likes**, **commentaires** et **retweets**.
- Compteurs dynamiques sur chaque tweet.
- Gestion des notifications basiques.

###  Réseau social
- Système d’abonnement / abonné (follow / unfollow).
- Visualisation de la liste des abonnés et abonnements.

###  Autres fonctionnalités
- Interface responsive avec **TailwindCSS**.
- Architecture **MVC** claire avec AdonisJS.
- Base de données relationnelle **PostgreSQL**.
- Gestion centralisée des erreurs et messages flash.
---

##  Technologies utilisées

| Technologie | Rôle |
|--------------|------|
| **AdonisJS 6** | Framework backend Node.js |
| **EdgeJS** | Moteur de template pour les vues |
| **PostgreSQL** | Base de données principale |
| **Lucid ORM** | Gestion des modèles et migrations |
| **TailwindCSS** | Design et mise en page responsive |
